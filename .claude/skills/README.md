# Vendored skills

These five skills are copied from [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills) at commit `0e181866f095b5f06d005133876e926515390d95`, unchanged. Each one was read in full on 2026-10-30 before being added: they are Markdown only, with no scripts, no tool permissions and no instructions beyond three.js advice.

They target three.js r186. Update them by reading the new versions the same way, never by installing over these.

`threejs-fundamentals` is left out on purpose, because it shows loading three.js from a CDN. Games here bundle everything.
